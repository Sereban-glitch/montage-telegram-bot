# 🎬 Монтажная Кухня (Montage Kitchen)

## 🚀 Ключевые возможности

### 1. Telegram Mini App (Frontend)
- **Вкладка «Монтаж Shorts» (1080×1920)**:
  - Загрузка видеофайла или вставка прямой ссылки / YouTube.
  - Настройка титула и подзаголовка.
  - Двуязычный режим субтитров (укр речь + рус субтитры, укр/укр, рус/рус).
  - Интерактивный ползунок выбора кадра для вертикальной обложки (1080×1920) с золотым оформлением.
  - Переключатель нормализации звука EBU R128 (`loudnorm=I=-14:TP=-1.5:LRA=11`).
- **Вкладка «Монтаж Long» (1280×720)**:
  - Нарезка пауз и тишины (настройка порога в секундах, например > 2.5 сек).
  - Транскрипция Whisper (`large-v3-turbo` / `small`).
  - Генерация горизонтальной обложки 1280×720 и глав/таймкодов для описания.
- **Вкладка «Витрина / Портфолио»**:
  - Карточки готовых работ (судебные заседания, нарезка по КСУ, выступления Сергея Величко) с постерами и встроенным видеоплеером.
- **Вкладка «Мои задачи»**:
  - Прогресс-бар (0–100%), этап рендеринга в реальном времени, позиция в очереди FIFO, кнопка скачивания готового `final.mp4`.

### 2. Админ-панель
- **Мониторинг очереди**: текущая задача в слоте, длина очереди ожидания, потребление ОЗУ (в пределах 12 ГБ бюджета).
- **Пользователи**: просмотр суточного расхода лимитов (по умолчанию 3 задачи/день для гостей, 10+ для админа), блокировка.
- **Каналы YouTube**: статус подключения OAuth токенов канала (`@humanrightszp`, ID `UC1KtjDqNXlN6qqXVUh0Y5Mw`), профили публикации.
- **Витрина**: управление публичными карточками готовых видео.
- **Терминал событий воркера**: отображение логов конвейера в реальном времени.

### 3. FIFO Worker (Защита памяти)
- На сервере выделено 12 ГБ ОЗУ.
- Воркер гарантирует **строго 1 активную задачу рендеринга** в момент времени.
- Никаких параллельных запусков FFmpeg / Whisper, приводящих к OOM killer.
- Задачи встают в очередь `queued` и берутся строго в порядке поступления (FIFO).

## 🛠️ Быстрый старт

### 1. Настройка переменных окружения
Скопируйте пример конфига и укажите токен Telegram-бота:
```bash
cp .env.example .env
```
В файле `.env`:
```ini
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА_ИЗ_BOTFATHER"
WEBAPP_URL="http://localhost:3000"
DATABASE_URL="file:./db/custom.db"
```

### 2. Запуск через Docker Compose (Рекомендуется для продакшена)
```bash
docker-compose up -d --build
```
Поднимает 3 контейнера:
1. `montage_webapp`: Mini App + Admin Panel на порту 3000.
2. `montage_bot`: Telegram-бот на Python `aiogram 3`.
3. `montage_worker`: Фоновый FIFO воркер с установленным `ffmpeg` и шрифтами `DejaVu Sans`.

### 3. Локальный запуск для разработки

#### Шаг A: Запуск WebApp & API
```bash
npm install
npx prisma generate
npm run dev
```
Интерфейс доступен по адресу: `http://localhost:3000`

#### Шаг B: Запуск Telegram-бота
```bash
cd services/bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python main.py
```

#### Шаг C: Запуск FIFO Воркера
```bash
cd services/worker
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python worker.py
```

## 📦 Интеграция с движком Sereban-glitch-video-montage v2.0.0

Движок монтажа подключён через скрипты:
- `scripts/short/render_short.py`: сборка вертикального кадра 1080×1920 (размытый фон + центр 1080×608 + золотая рамка `0xE8C547` + субтитры DejaVu Sans Bold с размером шрифта 48 на подложке `&HAA000000`).
- `scripts/short/thumb_short.py`: обложка 1080×1920 на выбранном проценте хронометража.
- `scripts/publish/upload_youtube.py`: выгрузка готового ролика на YouTube-канал в статус `private` с установкой обложки.
